# 🎬 Sol MCP Server — Demo Prompts

## Quick Demos (20 seconds each)

### Demo 1: "What's happening on Solana?"
> *"What's the current SOL price and network gas fees?"*

### Demo 2: "Check a wallet"
> *"Analyze this wallet: 7... (paste a real address). Show me SOL balance, token holdings, and recent transactions."*

### Demo 3: "Token research"
> *"Search for the BONK token and show me its price."*

### Demo 4: "DeFi quote"
> *"Get a swap quote for 0.1 SOL to USDC with 0.5% slippage."*

### Demo 5: "Portfolio overview"
> *"Analyze this wallet and tell me the estimated USD value."*

## Recording Tips
- Use a clean terminal with large font
- Show the MCP connection indicator in Claude
- Keep each demo under 30 seconds
- Add captions explaining what's happening
